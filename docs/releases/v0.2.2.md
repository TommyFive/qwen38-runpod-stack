# v0.2.2 — Qwen38 SGLang minimal-v2 B

A smaller, GPU-validated SGLang image for **Qwen3.8-27B NVFP4 + DFlash2** on NVIDIA RTX PRO 6000 Blackwell. It preserves CUDA, PyTorch, FlashInfer and the inference stack while removing redundant build artifacts and CUDA library copies.

**Versioned image:** `ghcr.io/tommyfive/qwen38-sglang:v0.2.2`
**GPU-tested source image:** `ghcr.io/tommyfive/qwen38-minimal-v2-checkpoint@sha256:820c0ef5e0752c0243946dbdce342cc8d363c1d5e115aa19c04fe497e51400c7`
**Rollback:** `ghcr.io/tommyfive/qwen38-sglang:v0.2.0`

## Exactly what changed

**Official upstream → minimal-v1:** The build selects the empty `qwen38-minimal` extra instead of SGLang's `all` extra, omitting **25 direct optional requirement declarations**: diffusion (20), HTTP/2 (1) and tracing/OpenTelemetry (4). Base Python dependencies remain unchanged. These are omitted *dependency declarations*, not a claim that every named package is absent from the filesystem.

**Minimal-v1 → minimal-v2 B:**

| Change | Files | Original uncompressed bytes |
|---|---:|---:|
| Removed Rust `*.rlib` compiler archives | 597 | 998,069,614 |
| Removed Rust `*.rmeta` compiler metadata | 595 | 667,264,896 |
| Replaced SHA-256-identical CUDA library copies with symlinks | 11 | 1,679,571,048 |
| **Total** | **1,203** | **3,344,905,558** |

Rust files were removed from `/sgl-workspace/sglang/rust/target/release/deps/`. CUDA wheel copies under `/opt/sglang/lib/python3.12/site-packages/nvidia/cu13/lib/` now link to identical system libraries under `/usr/local/cuda-13.0/targets/x86_64-linux/lib/`. **No CUDA functionality or nonidentical NCCL/cuDNN versions were removed.**

## GPU validation

On **RunPod US-KS-2 Secure Cloud, RTX PRO 6000 Blackwell**, both runtime modes completed **15/15 measured SGLang generations**:

| Mode | Technical | Code | Code edit |
|---|---:|---:|---:|
| **Lean** (direct API) | 133.72 tok/s | 182.89 tok/s | 196.09 tok/s |
| **Full** (+ OpenWebUI) | 134.54 tok/s | 186.26 tok/s | 194.19 tok/s |

Values are median decode throughput. Private Tailnet HTTPS and API-key enforcement were verified; unauthenticated API requests returned **HTTP 401**. Full mode installed **OpenWebUI 0.11.4** at runtime and passed its health/authentication endpoint checks. The uncached Docker image pull took **190 seconds**; model startup measurements belong to a separate, cached container restart.

## Runtime and deployment

- **Lean (`SERVE_WEBUI=0`):** SGLang API only. No OpenWebUI installation or listener.
- **Full (`SERVE_WEBUI=1`):** OpenWebUI is installed on demand into an isolated environment. **OpenWebUI and `uv` are not bundled in the Docker image.**
- RunPod templates carry the corrected bootstrap (`/workspace` handling, verified on-demand `uv`, installation logs and readiness checks) separately from the immutable image.
- Both public and private Tailnet deployment configurations are supported. Versioned minimal-v1 image/templates remain available for rollback.

The immutable image retains its original checkpoint-era OCI description label; the GPU runtime evidence above records its subsequent validation without changing the tested image digest.
